# Accessibility

NZJOSH XP aims to make its desktop experience usable with a keyboard, pointer and
touch, while respecting reduced-motion preferences. Improvements and reports of
barriers are welcome. This statement is not a claim of WCAG certification or a
completed independent accessibility audit.

## Controls and supported environments

- Use current Chrome, Edge, Firefox or Safari, with JavaScript enabled.
- A skip link leads to desktop applications. Desktop icons support keyboard
  selection and Enter to open; touch interactions adapt to the device.
- Standard window controls and menus expose accessible labels and visible focus
  styles. Chat uses a live message log and notification announcements.
- System reduced-motion preferences affect the racing transition and taskbar car.
  The tray control can turn the decorative car off.
- Windows adapt to smaller screens. Browser zoom remains available.

## Known limitations

The XP desktop metaphor, draggable windows and simulated programs may be harder
to navigate with assistive technology than a conventional document website.
Some canvas-based game or Paint interactions are visual and pointer-oriented.
The decorative racing circuit is not a substitute for an accessible data display.
Third-party destination websites have their own accessibility behaviour.
Compatibility can vary by browser, screen reader, device and zoom level.

## Report a barrier

Use the Bug report template and describe the affected window/control, release
version, browser, assistive technology, reproduction steps and expected behaviour.
For private reports, use Contact Me at https://nzjosh.com/. Do not share personal
information or unredacted screenshots in public issues. There is no guaranteed
response time, but actionable reports help prioritise improvements.
