# Security policy

## Supported versions

Security reports are reviewed against the latest public release and current
default branch. Older snapshots are not separately maintained. This personal
project has no guaranteed response or remediation timeframe.

## Report a vulnerability privately

Use the Contact Me window at https://nzjosh.com/ and identify the NZJOSH XP
repository and affected version. In your initial message, describe the issue's
general nature and ask for a private channel for sensitive reproduction details.
Do not put credentials, personal records, exploit payloads or private photographs
in public issues, pull requests or screenshots.

Include affected components, expected versus actual behaviour, browser/version,
impact and the minimum safe reproduction steps. Test only your own local copy or
systems you are explicitly authorised to assess. Do not access visitors' data,
disrupt the live site or perform social engineering.

If a secret was exposed, revoke or rotate it immediately. Deleting a file or
rewriting history does not invalidate a leaked secret or erase existing copies.

Coordinate disclosure with the maintainer while a report is assessed.
