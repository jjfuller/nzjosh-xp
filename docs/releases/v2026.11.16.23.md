## NZJOSH XP — public source snapshot

Website version **2026.11.16.23**, released November 16, 2026.

### Included

- Complete public desktop client, with personal content removed.
- Classic XP and McLaren-inspired appearances, five-light start sequence,
  asynchronous circuit preparation, simulated timing and taskbar racer with
  distance-synchronised rotating wheels.
- GitHub link on the right side of Start, using the existing external-link
  confirmation and matching neighbouring label colours in both themes.
- Expanded McLaren and lights-out README sections with five feature screenshots.
- Dedicated credits for Joshua Fuller and ChatGPT by OpenAI.
- Community guidelines, accessibility and security/support policies, issue and pull request templates,
  the MIT License for original code/documentation and separate third-party notices.

### Privacy and rights

Profile fields, albums and personal answers remain blank or generic. Personal
photos, portraits, certificates, resume documents, contact details, account links,
secrets and private editor/deployment tools are excluded. Screenshots show design
features rather than private profile content.

Original code and documentation are **MIT licensed**. Third-party artwork,
trademarks, fonts and images retain their respective owners' rights and are not
relicensed by this release. Read THIRD_PARTY_NOTICES.md before reusing assets.

### Run locally

Unzip the public package, use Node.js 22 or newer, run `npm start`, then open
http://127.0.0.1:4173/. No dependency installation or API key is required.

The live website was not redeployed as part of this repository release.
