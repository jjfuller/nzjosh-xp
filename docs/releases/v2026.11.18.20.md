# NZJOSH XP 2026.11.18.20

This release updates the sanitized public client from live website build
2026.11.18.20. It combines the changes since public release 2026.11.18.10.

- Add a compact XP-style analytics consent prompt that waits for desktop login,
  remembered choices, withdrawal and accessible tray preferences.
- Add blue-screen About and Privacy pages with matching privacy controls and
  working Resume, Certificates and Contact navigation through normal login.
- Require the user tile again after every refresh; preserve saved preferences.
- Make the hidden tray compact, with hover, focus and notification toggle states.
- Add login/logoff audio integration, mute/volume support and safe restart timing.
- Retain icon wrapping, group dragging, single-window Explorer, McLaren animation,
  local Josh Bot and the existing games and desktop applications.
- Improve local directory-page serving and document deployment configuration.

The public profile and credential collections remain empty. No personal photos,
resume files, contact information, account/server addresses, Google measurement
ID, private Worker export or deployment secrets are included. Supplied sound
recordings are excluded; optional audio and Analytics are disabled by default.
The live website is not changed by this repository release.
