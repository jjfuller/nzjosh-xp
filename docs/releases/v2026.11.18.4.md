## Updated desktop client and documentation

This release follows website version **2026.11.18.4**, with personal content removed.

### Newer interface and behaviour

- My Computer desktop entry, connected Explorer toolbars, menus and breadcrumb paths.
- Refreshed XP desktop/window icons and grouped certificate folders, with touch,
  keyboard and thumbnail hover/focus interactions.
- Shared image/PDF document viewer with document download and print controls.
- Classic appearance on refresh, new visits, page leave/return and switching away
  from the tab; Papaya remains available through Command Prompt during a visit.
- Personal-photo drag, context-menu and save/print deterrents, scoped so resume and
  certificate documents keep their download/print controls. These measures cannot
  prevent screenshots or determined extraction of public images.
- Fourteen locally hosted software logos with provenance and rights notices in
  About this desktop. Recently Used represents the owner's software toolkit.
- Papaya contrast fixes, five-light start, circuit preparation, decorative timing,
  taskbar McLaren animation and the scripted, no-AI Josh Bot.

### Public project cleanup

- Updated README, new interface screenshots and a module-by-module architecture guide.
- `npm run check` verifies syntax, local imports and the empty personal-data boundary.
- Blank profile, generic FAQ answers and empty certificate/award/course collections.
- No personal albums, photographic portraits, resume files, certificate scans,
  credential IDs, personal account links, secrets or private deployment/editor tools.
  The Josh Bot cartoon remains an explicitly approved documentation image.

### Run locally

Use Node.js 22 or newer. Run `npm start` and open http://127.0.0.1:4173/.
Run `npm run check` before publishing a modified public copy. No dependency
installation or AI API key is required for the static template.
