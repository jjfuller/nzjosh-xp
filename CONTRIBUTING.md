# Contributing to NZJOSH XP

Reviewed November 18, 2026.

This is a personal, plain HTML/CSS/JavaScript desktop project. Discuss substantial
changes in an issue before starting. Contributions are reviewed at the maintainer's
discretion; there is no guaranteed response time or deployment commitment.

## Before submitting

1. Read the README, code of conduct, security policy, LICENSE and third-party notices.
2. Use Node.js 22 or newer and run `npm start` for a local preview.
3. Keep changes focused and preserve XP and McLaren appearance, keyboard access,
   mobile interactions, external-link confirmation and reduced-motion behaviour.
4. Run `npm run check` for syntax, local imports and the public-content boundary, then `npm run test:local` to verify HTTP serving and public assets.
5. Verify the affected interaction in relevant desktop and touch layouts. Include
   browser/device details and screenshots without personal information.
6. Use the pull request template to explain the problem, change and validation.

## Privacy and assets

The public source is intentionally a blank personal-content template. Do not add
personal biographies, emails, phone numbers, account links, portraits, photo
albums, certificates, resume documents, API keys, environment files or private
deployment/editor tools. Use synthetic examples for reproduction steps.

Do not add third-party assets without documented permission and appropriate
notices. AI-assisted changes must be reviewed by the contributor; describe the
assistance when it materially affects the submitted work.

## Permissions

Original application code and documentation are MIT licensed. By submitting
original code or documentation for inclusion, you agree to provide it under the
same MIT terms. Submit only material you have permission to share and license.
Third-party assets are excluded from the project's MIT licence unless their
owners separately provide compatible permissions. Do not assume a copyright
transfer or permission to relicense someone else's work.

Report vulnerabilities privately using SECURITY.md, not a public bug report.
